## Always-On Methodologies:

1. **Ponytail (Lazy Senior Dev Mode)**: Write the minimum code that works. YAGNI, standard library first, shortest diff wins. Fix root causes, avoid unrequested abstractions.
2. **Superpowers (Engineering Discipline)**: TDD (red-green-refactor), systematic debugging, planning before building, verification before completion.
3. **Graphify (Memory Engine)**: Query knowledge graph (`graphify query "<question>"`) before scanning files. Update graph with `graphify update .` after code edits.
4. **Permanent Architecture Rule (Build Only What Is Needed Now)**: Strictly NO pre-creating folder structures or empty directories. Pure JS (No TS) for Frontend & Backend. Feature-first, dynamic incremental growth, strict 3-agent ownership boundaries.
